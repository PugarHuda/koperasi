The co-ops' federation

A secondary co-op, as Indonesian co-op law allows (Law 25/1992 art. 15–16): an unmodified Sputnik DAO whose only members are co-ops' DAOs, one co-op one vote. A co-op votes there only when its own members approved a proposal that casts the vote. Co-ops that recognise each other count each other's work records (the passport).
